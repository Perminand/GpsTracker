Микро-сервисное приложения для отображения данных с сайта wialon.com. Приложение имеет трех страничный html интерфейс. На первом идет авторизация пользователя и генерация jwt ключа. На второй отображается полученные сообщения в wialon. Третья страница "Админка" С возможностью добавлять пользователей.
